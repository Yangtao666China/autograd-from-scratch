# 为什么梯度要这样传播？

## 1. 本地导数与上游梯度

每个输出 Tensor 保存父节点以及一个局部反向函数。对 `z = x*y`，来自损失的 `dz` 乘上 `y` 传回 `x`，乘上 `x` 传回 `y`。局部规则拼接起来就是链式法则。

## 2. 广播的反向是求和

`(batch, features) + (1, features)` 在前向重复使用同一行偏置。反向必须把 batch 维的贡献加回 `(1, features)`，否则参数的梯度形状和含义都不正确。`_unbroadcast` 先消除新增的前导维，再对原来长度为 1 的维求和。

## 3. 拓扑顺序与重复使用

对 `y = x*x; z = y+y+x`，应当先处理 z 的所有下游贡献，再执行 y 的反向规则。本实现用迭代后序遍历，节点按身份去重，避免共享节点被重复执行，也不受 Python 递归深度限制。

`backward()` 保留叶子节点累计梯度，但每次清零中间节点。否则对同一张图调用两次 backward 时，中间梯度会重复累积并污染结果。每次优化前仍应清零参数梯度。

## 4. 稳定的二分类损失

对 logit `z` 和标签 `y`，BCE 可以写成 `softplus(z) - y*z`。`logaddexp(0,z)` 避免直接计算 `exp(1000)` 溢出，softplus 导数也用稳定表达式求 sigmoid。

## 5. 为什么要有数值梯度检查？

测试用中心差分 `(f(x+h)-f(x-h))/(2*h)`，独立验证解析梯度。它会比反向传播慢，适合小张量测试。ReLU 在零点不可微，所以差分测试选择远离零点的输入。

## 6. 实验边界

训练、验证和测试样本分别生成；模型只依据验证 BCE 选取参数。默认最优轮次恰好是最后一轮，这仍是依据记录计算的结果。一个种子的良好测试分数不构成广泛有效性的证据。
